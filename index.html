配置 API 密钥

请前往 https://vsllm.com 获取您的专属密钥
密钥仅保存在您的本地浏览器中。

必须创建新令牌，并选择 image_2fen 分组。

到时间会自动停止并提示可重试。默认永不超时，一直等后端返回。

仅对网络错误、HTTP 5xx、超时自动重试；参数错误 / 401 / 403 / 400 不重试；手动取消不重试。

编辑/标记图片

圈出想改的位置，保存后这张图会放进待发送区，再在输入框里写类似"修复红圈内的手"、"把圈住的区域换成XXX"的指令发出去。

截取视频帧

从本地视频提取一帧作为参考图。
纯前端处理，不会上传视频本身，只把截取到的图加入待发送区。
